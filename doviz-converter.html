How to use

Straightforward by design

Four interactions, that's all. Open it, pick your currencies, type a number, done.

01

Pick your currencies

Tap either currency button to open the search sheet. Type a code or name, then tap to select.

02

Type an amount

Enter a number in either field - the other recalculates instantly using the live rate.

03

Swap if needed

Tap the swap button between the fields to flip the pair and recalculate in one motion.

04

Rates stay fresh

Each pair is cached for 1 hour. The status line under the amounts shows the live rate and cache status.

Installation

Pick your platform

Both builds come from the same Flutter codebase - install whichever fits your device, or both.

🐧

Linux

Primary · .deb
1

Download the package

Grab the .deb file directly, or with wget in your terminal.

wget https://otek.today/files/otek-doviz-converter_1.0.14_amd64.deb
2

Install with apt

Installs the app and pulls in any missing dependencies automatically.

sudo apt install ./otek-doviz-converter_1.0.14_amd64.deb
3

Launch it

Find it in your application menu, or launch directly from the terminal.

otek-doviz-converter

Built for amd64 (x86_64) systems. Debian, Ubuntu, Mint, Pop!_OS, and derivatives are supported.

📱

Android
